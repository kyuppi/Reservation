# 店舗向けWEB予約システム（GitHub Pages + Google Apps Script）

HTML / CSS / JavaScript / Google Apps Scriptだけで動く、店舗向けの買い切り型WEB予約テンプレートです。

## できること

- 予約画面と管理画面を完全分離
- GitHub Pagesで公開可能
- `/admin/` を管理画面URLにできる
- 管理画面はパスワード保護
- 管理画面からパスワード変更
- スマホ最適化
- 店舗名変更
- 予約画面の背景画像URL変更
- メニュー追加・編集・削除
- メニューの売り切れON/OFF
- メニューごとのトッピング追加・編集
- トッピングが0件なら予約画面にトッピング欄を表示しない
- 臨時休業日追加・削除
- 来店日・時間・人数・名前・電話番号・メールアドレス入力
- メニュー数量・トッピング選択
- 予約をGoogleスプレッドシートへ保存
- 管理画面で予約一覧を確認
- 予約通知メールの送信先を管理画面から変更
- 新規予約時にGmail / Google Workspaceのメール送信機能から通知

## 1. Googleスプレッドシートを作る

1. Googleスプレッドシートを1つ新規作成。
2. 「拡張機能 → Apps Script」を開く。
3. `gas/Code.gs` の内容をすべて貼り付ける。
4. Apps Scriptの「プロジェクトの設定」でタイムゾーンを `Asia/Tokyo` にします。
5. Apps Scriptエディタ上部の関数選択で `setup` を選び、1回だけ実行します。必要なシートが作成され、対象スプレッドシートが紐づけられます。
6. その後、ウェブアプリとしてデプロイします。

## 2. ウェブアプリとしてデプロイ

Apps Scriptの「デプロイ → 新しいデプロイ → ウェブアプリ」で、次のようにします。

- 次のユーザーとして実行：自分
- アクセスできるユーザー：全員

発行されたURL（`https://script.google.com/macros/s/.../exec`）をコピーします。

## 3. GitHub Pages側の設定

`js/config.js` のこの部分だけ、初回に1回設定します。

```js
GAS_WEB_APP_URL: 'ここにApps ScriptのウェブアプリURL'
```

それ以外の店舗運営中の変更はコードを触りません。

## 4. GitHubにアップロード

このフォルダをそのままGitHubリポジトリへアップロードし、GitHub Pagesを有効にします。

ファイル構成：

```text
index.html
admin/index.html
admin/admin.js
admin/admin.css
css/style.css
js/config.js
js/api.js
js/app.js
gas/Code.gs
README.md
```

GitHub PagesのURLが

```text
https://あなたのユーザー名.github.io/リポジトリ名/
```

なら、予約画面はそのURL、管理画面は

```text
https://あなたのユーザー名.github.io/リポジトリ名/admin/
```

です。

## 5. 初期パスワード

初期パスワードは `gas/Code.gs` の `INITIAL_ADMIN_PASSWORD` です。

初回ログイン後は、管理画面の「設定 → 管理者パスワード変更」から変更してください。

## 6. 管理画面での運用

「設定」から店舗名・背景画像URL・予約通知先メールを変更できます。

「メニュー」からメニューを追加・編集でき、「売り切れにする」で予約画面に注文できない状態にできます。

「メニュー編集 → トッピング」で、メニューごとにトッピング名と追加料金を登録できます。登録が0件のメニューは予約画面にトッピング欄が出ません。

「臨時休業日」から日付を追加すると、その日は予約画面で予約できません。

「予約一覧」では、次の項目を表示します。

- ご来店日時
- お名前
- 人数
- 予約した時間
- 電話番号
- メールアドレス
- 注文内容
- 合計金額
- 予約状態

## 注意

この構成はGitHub Pagesの静的サイトとGoogle Apps Scriptの間をJSONPで接続しています。予約用サイトとして実運用する場合は、公開範囲とスプレッドシートの共有設定を「店舗運営に必要な人だけ」にしてください。

また、背景画像は管理画面から「画像URL」を変更する方式です。GitHubのコードを編集せずに背景を変更できます。
